# Deployment checklist

- [ ] Supabase project created
- [ ] `supabase/setup.sql` executed without errors
- [ ] Email/password provider enabled
- [ ] Repository imported into Vercel
- [ ] `VITE_SUPABASE_URL` configured
- [ ] `VITE_SUPABASE_PUBLISHABLE_KEY` configured
- [ ] New Vercel deployment created after variables were added
- [ ] Account signup tested
- [ ] Email confirmation tested, if enabled
- [ ] Sign-in tested
- [ ] Add/edit/delete tested
- [ ] Drag-and-drop tested
- [ ] Revision rating tested
- [ ] Overdue revision remains visible
- [ ] Same account tested on a second device
- [ ] Different account confirmed unable to see the first account's state
- [ ] JSON backup downloaded
